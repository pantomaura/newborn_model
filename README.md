# Newborn Model

Teaching materials for the MA course 'Mechanisms of First Language Acquisition' at the University of Erfurt, winter semester 2026/2027.

## Data

### plural_marking_acquisition.ipynb
Google Colab notebook to simulate the acquisition of nominal plurality marking in an artificial language.
